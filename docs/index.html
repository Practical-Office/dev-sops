One front door for how we work: three intake loops on Team Work, each with its own course and Cursor skill chain.

Intake chooser

Every new Team Work card gets exactly one Ticket Type:

LabelWhenCourse
BMLRisky assumption / experimentBuild-Measure-Learn → BML Board
BugBroken known behaviorBug Handling SOP
UpdateDecided outcome — not a learning betUpdate Handling SOP
1 · Build-Measure-LearnHypothesis · Measure · Learn / kill 2 · Bug HandlingReport → Triage → Diagnose → Fix → RCA 3 · Update HandlingDecided work · Build skills · Acceptance verify

Skills by loop

Each course has a Skills section in its sidebar (same pattern as BML). Open a course, then open a skill page.

LoopPrimary chainSkill pages
BML /grill-with-docs → /to-spec → /to-tickets → /implement Open BML skills
Bug /diagnosing-bugs → /tdd → /code-review (+ /triage, grill at intake) Open Bug skills
Update /grill-with-docs → /to-spec → /to-tickets → /implement Open Update skills

Shared across loops: /grill-with-docs, /grilling, /tdd, /code-review, /wayfinder (optional).

Hard truths

  • If an Update needs pass/kill criteria, it is not an Update — promote to BML.
  • Do not run fake Measure/Learn on Updates.
  • BML cards move to the BookIQ BML Board after intake.
